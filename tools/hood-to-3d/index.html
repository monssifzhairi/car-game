🛠️ Kifach ndiroha kamla?

1

1. Chouf l preview hna

Khtar l7oma dyalk lfou9 o chouf wach OSM 3amer fiha buildings o tri9an. Ila kant khawya → zid dir contribution f openstreetmap.org

2

2. Blender b Blosm (fabor, free)

T7el Blender → Edit → Preferences → Add-ons → install Blosm (free). O dir import direct mn OSM b nafs coordinates. Ghadi ijik roads + buildings extrudés b7al Mehdia v4 li 3ndk.

3

3. Siftha l Godot ka game

F Blender: Export → glTF (.glb). F Godot 4: import .glb → zid CollisionShape. O t9der tsog b tomobil direct!

💡 Nasi7a: L7oma dyal Mehdia li f screenshots dyalk deja m7awla mzyan! Ila bghiti n3awnk n7awlha direct l Godot road mesh + collision, gouli liya fin kayna l file .blend o nsayb lik script.
